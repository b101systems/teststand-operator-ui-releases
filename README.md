# TestStand Operator UI Releases

Official Windows MSI releases for TestStand Operator UI.

TestStand Operator UI is the operator screen for NI TestStand 2025 stations: the operator signs in
with a TestStand user, opens a project and presses START, and the app shows every socket and every
step live, read from TestStand, without changing the sequence.

Download the installer from the [Releases](../../releases) page.

TestStand Operator UI is a Bravo-101 Systems product; it is not an NI product. NI TestStand is a
trademark of National Instruments (Emerson).
